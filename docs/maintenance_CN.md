# 维护与本地验证

本文档负责 CLEAN-01，即 2026-10-20 获批的仓库整理工作，记录实现契约、本地检查和证据限制。音频、同步、其他平台及发布批准不属于该范围。

## 契约

实现列中的路径相对于 apps/windows/；以 packages/ 开头的路径除外。

| 契约 | 要求行为 | 实现与检查 |
| --- | --- | --- |
| CLEAN-STORAGE | 写入前校验连续的章节/分句位置和唯一标识。拒绝格式损坏的持久化 JSON。数据库或缓存操作失败时，回滚数据库删除。 | native/src/storage.rs；隔离 SQLite 测试，覆盖写入/删除被拒绝、JSON 损坏、位置非法及缓存删除失败 |
| CLEAN-PATHS | 调试数据相对于编译时的检出目录解析；打包数据使用操作系统的应用本地目录。不硬编码开发者盘符。 | native/src/paths.rs；移动检出目录测试；storage_location IPC |
| CLEAN-READER | 句子显示与导航使用从零开始的位置。原生删除失败时保留书架。忽略重导入或删除后才返回的加载结果。 | src/text.ts、src/stores/library.ts；使用真实模块和模拟 IPC 的回归测试 |

公共解析函数签名、IPC 命令名、序列化字段和保留语义保持兼容。内部可见性按需收窄。Vue 文件名使用 PascalCase。

## 存储与生命周期限制

可读正文存储于 SQLite。原始 TXT 字节单独缓存于 cache/<book-id>.txt。导入失败可能留下无引用缓存。缓存删除成功后若数据库提交失败，可读书籍可能仍然存在，但缺少可选的原始缓存。不保证跨资源的崩溃原子性。

SQLite 使用 WAL 和 synchronous=NORMAL。进程故障与断电持久性是不同问题；断电持久性尚未完成合格性认定。保留现有的 description 字段和核验表增量初始化。测试使用内存数据库或唯一命名的临时数据库，不操作运行中应用的数据库。

播放定时器仅演示句子高亮，不提供 TTS 或真实音频播放。当前纯文本书籍隐藏播放控件。浏览器预览为临时状态。连续阅读追加章节，尚未限制 DOM 窗口大小；长时间会话的内存占用未经测量。

## 本地检查

[development.json](../development.json) 是由 [tools/check.cjs](../tools/check.cjs) 校验的第 1 版本地反馈注册表，记录组件后果等级、已验证环境、命令及单进程时限（毫秒）。组件分级不代表其验证义务已经满足。

- validate 检查字段、标识、路径、程序、等级及时间上限，不执行检查。
- collect 要求匹配已登记的 Windows x64/工具链标识，并按顺序单次执行每项检查，不下载依赖，不启动应用或服务。
- 每个进程具有时限和 8 MiB 输出上限。Windows 超时清理针对所属子进程树。
- 日志、退出状态、时间戳、哈希及执行前后的源内容清单按唯一的本地运行标识保存。
- 失败、超时、输出不完整或源内容漂移均保留为检查失败。重跑须有已诊断原因、输入变更或其他具体的验证需要。
- 回执为本地未封签记录。哈希可检测意外修改，不是独立的时间戳或签名。

正式模式、审批注册表、义务展开、覆盖率/MC-DC 与变异测试核算、可信采集及发布门禁仍属于 GAP-04。本地运行器不提供具备发布资格的结果。

## 格式与生成文件

Rust 使用锁定的工具链、rustfmt.toml 和严格 Clippy 检查。前端使用已安装的 TypeScript 格式化器，要求命名函数显式声明返回类型，并采用 PascalCase Vue 文件名。在 apps/windows/ 中运行 pnpm format 应用脚本格式，运行 pnpm lint 检查。模板/CSS，以及完整的命名与注释规范仍需审核。

ts-rs 测试从 protocol/src/lib.rs 生成 TypeScript 绑定，不得手工修改。原生生成模式、构建产物、依赖、用户书籍及本地数据不属于手写源码。

## 已跟踪证据与本地诊断材料

[文档治理](documentation_CN.md)规定准入条件。八份已被引用的核心 JSON 结果继续跟踪。原始日志、ZIP 备份、源码快照、中间 JSON 和时间戳运行目录仅在本地保留；2026-10-20 的修正将其中 111 个文件及一个空占位文件移出追踪，不删除本地字节内容。

当前整理结果索引为 [2026-10-20-cleanup/result.json](evidence/2026-10-20-cleanup/result.json)。其他结果由[任务台账](tasks_CN.md)、[里程碑索引](worklog_CN.md)和[架构文档](architecture_CN.md)引用。

保留回执描述原执行的输入与结果。其中的日志、备份和运行目录引用指向本地诊断材料，并不承诺全新克隆包含这些文件。原哈希和执行结果保持不变。缺少本地材料会限制回放能力，不能因此判为通过。不得仅为替换排除的产物而重跑测试或改写结果。

现有本地产物在 .git/info/exclude 中按明确路径排除。新运行仍须进行准入审核；该本地清单不是后续运行的通用策略。应按已批准路径暂存。Git 不备份已忽略或未跟踪的诊断材料。

原书测试需要 SAGA_SAMPLE，独立于默认测试套件。范围内的测试/构建不代表桌面验收、完整覆盖率、MC/DC、定向变异测试合格性认定、其他平台支持或再分发就绪。[任务台账](tasks_CN.md)记录这些缺口。

应用生命周期、提交与发布由用户控制。CLEAN-01 未启停服务、安装依赖、迁移现有书籍或批准发布。后续提交需要单独授权。
